# 안녕하세요, 김종승입니다 👋

**공간정보(GIS) 기반 공공 웹서비스를 개발해 온 백엔드 개발자**입니다.
공공 SI에서 해양 분야 시스템을 맡아 공간 데이터 설계부터 지도 서비스 개발,
데이터 수집 파이프라인, 서버 구축·운영까지 경험했습니다.

## 🛠 Tech Stack

| 분야 | 기술 |
|---|---|
| Backend | Java, Spring MVC, 전자정부프레임워크 |
| Database | PostgreSQL, PostGIS |
| GIS | GeoServer, OpenLayers, WMS / WFS (OGC), VWorld API |
| Data | ETL 파이프라인 개발 |
| Infra | Linux (Rocky / RHEL / CentOS), Docker |
| WAS / Web | Tomcat, JBoss, Apache |

## 💼 주요 경험

- **GIS 웹시스템 개발**
  - 해양수산 분야 공공 웹사이트 다수 개발·운영
  - GeoServer로 공간 레이어를 발행하고 OpenLayers로 지도 서비스 구현
  - VWorld 및 외부 기관의 WMS/WFS 서비스 연동
- **공간 데이터 처리**
  - PostGIS 기반 공간 데이터 모델링 및 공간 쿼리 작성
- **데이터 파이프라인**
  - 해양 데이터 수집·정제·적재 ETL 구축 (2개 프로젝트)
- **인프라 운영**
  - WAS(Tomcat, JBoss) 및 웹서버(Apache) 환경 구성과 애플리케이션 배포
  - 운영 DB 서버 구축 및 보안 취약점 점검 대응
  - 사내 개발서버 네트워크 구성 (IP 할당, 포트포워딩 관리)
